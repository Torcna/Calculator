# Калькулятор на C++

Этот проект представляет собой калькулятор, реализованный на C++, который поддерживает выполнение математических выражений с различными типами данных и операциями. Калькулятор может работать с целыми и вещественными числами, переменными, а также с полиномами от одной переменной (x).

## Поддерживаемые входные данные

- **Целые и вещественные числа**
- **Переменные**, принимающие значения из следующих множеств:
    - Целые числа
    - Вещественные числа
    - Полиномы от одной переменной (x)
- **Операции**:
    - `+`, `-`, `*`, `/`, `%` (сложение, вычитание, умножение, деление, взятие по модулю)
    - Скобки `(`, `)`
- **Функции**:
    - `exp` (экспонента)
    - `sin` (синус)
    - `cos` (косинус)
    - `lg` (логарифм по основанию 10)
    - `sqrt` (квадратный корень)
